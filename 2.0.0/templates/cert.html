手机装证书（一次就够）

iPhone / iPad 打开本软件时白屏、没有报错，几乎都是同一个原因： 软件用的是自签名证书，苹果设备默认不信任它；而 Chrome / Edge 这类第三方浏览器 连"继续访问"的按钮都没有，所以直接白屏。

装一次下面这份证书并开启「完全信任」，之后 Safari、Chrome、Edge、夸克 全都能正常打开，也不用每次点"继续"。

第 1 步：下载证书

① 下载描述文件（iPhone / iPad 推荐） ② 下载证书文件 .crt（安卓 / 电脑用）

本机根证书： {% if has_ca %}已生成{% else %}尚未生成（请先在电脑上启动一次软件）{% endif %}； 版本 v{{ version }}

第 2 步：安装（iPhone / iPad）

  1. 用 Safari 打开本页，点上面的「下载描述文件」，弹窗点允许；
  2. 打开 设置 → 顶部「已下载描述文件」→ 点安装（要输入锁屏密码）；
  3. 再进 设置 → 通用 → 关于本机 → 证书信任设置；
  4. 把 「班级叫号器本机根证书」 的开关打开（完全信任）。
第 4 步不做的话，证书只是"装上了但没被信任"，仍然会白屏。 这一步 Apple 官方说明：手动安装的证书不会自动信任，必须在「证书信任设置」里手动开启。

第 3 步：重新打开软件

用下面任一地址打开（现在用 https 不会再有红色警告）：

    {% for ip in lan_ips %}
  • https://{{ ip }}:{{ secure_port }}
    • {% endfor %}
  • https://{{ hostname }}.local:{{ secure_port }} （需要设备支持 mDNS：苹果设备/电脑可以，部分鸿蒙等机型不行）
  • http://{{ hostname }}.local:{{ port }} / http://本机IP:{{ port }} （叫号用 http 也能开，激活/监控/远控必须 https）

装在安卓 / 鸿蒙上

  1. 点「下载证书文件 .crt」；
  2. 设置 → 安全（或「密码与安全」）→ 加密与凭据 → 安装证书 → CA 证书 → 选择刚下载的文件；
  3. 如提示"您的数据将被公开"之类，选仍然安装。

安卓上如果不装证书，也能用 http://本机IP:{{ port }} 叫号， 只是 https 的激活/监控会提示不安全。

还是打不开？按顺序试

  1. 打开 /plain —— 这一页不含脚本，能开说明网络没问题；
  2. 打开 /api/health —— 能出 JSON 说明连的是这台电脑；
  3. 设置 → 隐私与安全性 → 本地网络 → 找到你用的浏览器，打开权限；
  4. 设置 → 无线局域网 → 当前 Wi-Fi 右侧 ⓘ → 关闭「限制 IP 地址跟踪」、 关闭「私有 Wi-Fi 地址」；Apple ID → iCloud → 关闭「私密中继」；
  5. 清掉浏览器缓存，或换 Safari 再试；
  6. 电脑上打开 /logs 看运行日志，把内容发给我们。
小提示：Safari 是唯一能点「显示详细信息 → 访问此网站」跳过证书警告的； 第三方浏览器在 iPhone 上做不到这一点，所以它们显示的是白屏。
