这台电脑将变成教室的"叫号台"：随机点名、语音播报、手机遥控，都在这里设置。

手机可控同一 Wi-Fi 用账号密码登录
自动更新只下增量代码包

给这台电脑起个名字

手机、平板上打开 http://名字.local:端口 就能用，不用记 IP 地址。

手机访问地址：…

默认用电脑名。点「下一步」时会立刻保存并切换 mDNS，手机用 http://名字.local 马上就能打开； 但 https://名字.local（手机里的监控、文件、更新）要重启一次程序才会换用新名字的证书， 完成页会给你一个「 现在重启」按钮。

启动方式与更新策略

更新只下载增量代码包（约 0.14 MB）；运行环境缺依赖时才会额外下载。

用手机连接（可选）

手机连同一个 Wi-Fi，打开下面的地址，用软件账号密码登录就能操作本软件。 不用扫码配对，手机上也什么都不用装。

地址在哪看？装好后软件首页和「设置 → 手机访问」里都会显示 局域网地址（形如 http://192.168.1.19:8000）和二维码，手机照着打开即可。
第一次使用会要求创建管理员账号（用户名 + 至少 8 位密码）； 之后电脑和手机都用这个账号登录，公网访问也要密码。
想在家里 / 路上也能看？装完后到 设置 → 公网访问： 填一次 GitHub 账号密码，点「自动登录」，再给这台电脑起个隧道名即可 —— 以后不用再登录，登录失效会自动重登。

手机首次打开 https 会提示「证书不安全」，点「高级 → 继续访问」即可。
