内网服务

其他设备浏览器访问：http://主机名.local:端口（修改端口后需重启软件生效）

手机端“激活 / 监控 / 远程控制 / 文件传输”等敏感功能需通过 https://主机名.local:安全端口 访问（自签名证书，首次需点“继续访问”）。

监控和远控

画质越高越清晰、也越吃 Wi-Fi 带宽；用手机看讲台时建议「高清」，网络差就选「流畅」。

双指捏合＝Ctrl+滚轮（缩放），双指上下滑＝滚轮（滚动）。

「自动」会用 Windows 多点触摸 API 注入真实触点（支持双指手势）， 注入失败时自动退回鼠标，保证一定能点。
