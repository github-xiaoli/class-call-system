一、这东西是干什么的

「班级叫号器」是一个放在教室电脑上的随机叫号 / 点名小软件。它自带 Python 运行环境， 解压即用、不用安装，双击就能跑；随机叫号的同时会用语音把学号、姓名和老师姓名念出来。

功能说明
随机叫号按学号或直接点名单叫号，自动语音播报，可带备注（如"带上作业"）
名单管理支持导入 CSV 名条、手工增删、搜索、清空
叫号记录自动记录每一次叫号的时间、学号、姓名，可刷新、可清空
消息播报输入一句话，电脑用语音念出来（通知、提醒都行）
监控对讲看电脑摄像头画面、听电脑麦克风、用手机对讲
文件传输手机上直接浏览电脑文件、上传下载、新建/重命名/复制/移动/删除
远程控制手机当鼠标键盘遥控电脑，支持多点触控
手机访问同一个 Wi-Fi 下，手机浏览器输网址就能用，不用装 APP
密码授权敏感功能（监控 / 远控 / 文件 / 更新）需要本机创建密码后激活才可用
在线更新内置 OTA：自动测速选最快线路，只下增量代码包，下载完再点一下安装重启
常驻运行可开机自启、最小化到托盘，不占屏幕、不弹黑窗

二、第一次使用

2.1 启动软件

  1. 用安装包（推荐）：双击 班级叫号器_安装包_v2.0.19.exe（约 60 MB）。 安装向导一共 5 步：欢迎 → 许可协议 → 安装位置 → 安装 → 完成。 许可协议页显示的是 GNU GPL v3 的中文全文，勾选「我已阅读并同意上述许可协议」才能点下一步； 安装位置默认 C:\Program Files\班级叫号器，一般不用改。 中间会弹一次系统 UAC 提示，点「是」即可；最后一步可以直接勾上「立即启动」。
  2. 用绿色包：解压到任意目录（路径别带特殊符号），双击 start.bat。
  3. 启动后不会弹大窗口，屏幕右下角任务栏会出现一个托盘图标，软件已在后台运行。
  4. 想开机自动运行：网页里打开「设置 → 开机自启」并保存，以后开机自动在托盘里待命 （第一次申请管理员权限时点"是"，之后开机不再询问）。
托盘图标：左键弹出菜单，右键也是菜单。菜单里有「打开网页」「软件更新」「退出」。 有更新正在下载时，左键点托盘会直接打开更新界面。

2.2 打开操作界面

  1. 本机：浏览器打开 http://127.0.0.1:8000。
  2. 手机 / 其它电脑：连同一个 Wi-Fi，打开 http://主机名.local:8000 （主机名在设置里可改，默认 nine6），或者直接输电脑的局域网 IP。
  3. 敏感功能（监控、远控、文件、更新）在手机上需要走 https://主机名.local:9443， 首次会提示"证书不安全"，点「继续访问」即可。

12.3 下载完成 → 安装并重启

  1. 下载解压完成后蒙层自动消失，出现「✅ 安装并重启（版本号）」按钮，点它才开始真正切换版本。
  2. 安装前会先自检运行环境（依赖库是否齐全），检查不通过就不切换版本，原版本继续可用， 不会出现"更新完起不来"。
  3. 重启期间网页会短暂断开，几秒后刷新即可。
更新的机制（和"环境"有关）：更新包分两部分——"代码包"很小（约 0.14 MB，秒下）； "运行环境包"约 230 MB。软件先只下代码包，再对比新版本要求的依赖版本：
  • 依赖都满足 → 只下代码包，不下载环境包（几秒钟搞定）；
  • 有依赖缺失或版本不符 → 才去下载环境包补上。
下载前会同时向 31 个 CDN 镜像发请求测速，4 秒内选出最快线路；下载支持断点续传， 网断了自动续传，不会从 0 重来。

十三、常见问题

Q1. 手机打不开 / 提示证书不安全？
① 手机和电脑要在同一个 Wi-Fi；② 敏感功能必须用 https://主机名.local:9443， 自签名证书首次会警告，点「高级 → 继续访问」；③ 还不行就在 Windows 防火墙放行该端口的入站。
Q2. 9443 端口启动失败？
Windows 会把一段端口"保留"起来（Hyper-V / WinNAT 用），9443 正好落在保留段里时会报 WinError 10013。 软件会自动跳到未被保留的端口并记住它；也可以在设置里勾选「自动抢占系统保留端口」（需管理员）把 9443 抢回来。
Q3. 监控页摄像头列表是空的，或者画面和名字对不上？
列表按 Windows DirectShow 枚举到的真实设备顺序生成，和实际设备一一对应。 刚插上摄像头时刷新页面即可；个别虚拟摄像头（如 OBS）需要先启动它的虚拟设备。
Q4. 叫号没有声音？
设置里把「语音合成」改成离线语音试试（不依赖网络）；检查「叫号音量」是不是 0；系统音量是否静音。
Q5. 更新很慢或一直失败？
软件会并发测速 31 条线路并自动选最快的，下载中断会自动断点续传。 网络实在差时，可以在电脑上手动下载 release 里的 zip，用「手动上传更新包」安装。
Q6. 更新后想退回旧版本？
把 version.json 里的 version 改回旧版本号（旧版本目录还在）即可； 学生数据和叫号记录都存在 data/ 里，不会丢。
Q7. 数据存在哪？换电脑怎么办？
名单、记录、密码、配置全部在 data/ 目录，整个文件夹拷到新电脑的同名目录即可。
Q8. iPhone / iPad 打开一片白，什么提示都没有？
这是自签证书的问题：iPhone 上的 Chrome / Edge 没有"继续访问"按钮，所以直接白屏。 用 Safari 打开 https://电脑IP:9443/cert 装一次证书并开启"完全信任"即可， 详见 第十四章 14.3。
Q9. 手机输"名字.local"打不开，输 IP 就能开？
那是这台设备/系统不解析 .local（例如鸿蒙 3.0 的荣耀 30S）， 与浏览器无关。手机一律用 IP，详见 第十四章 14.2。
Q10. 昨天还能用，今天手机就连不上了？
最常见两种：电脑 IP 变了（旧二维码失效）、或校园 AP 限制多播 / 开了客户端隔离。 见 第十四章 14.5；电脑上的 /logs 能看到换网与重新注册的记录。

14.2 手机打不开 名字.local：取决于系统，不是浏览器

.local 这种名字要靠设备自己用 mDNS 解析。能不能解析，看的是 操作系统/ROM —— 同一个 Edge，在不同设备上结果就不同：

设备系统能否解析 .local
荣耀 30S鸿蒙 3.0（AOSP 10 底子）不能
Lenovo TB310FULineageOS 23 GSI（Android 16）能
iPhone / iPad / MaciOS / iPadOS / macOS能
Windows 10 / 11 电脑系统自带 mDNS能

所以"换浏览器能解决"是错觉：Chrome、Edge、夸克在安卓上都走同一个系统解析器。

结论：手机一律用 IP。软件里的二维码、配对地址、向导里的手机地址 默认已经都用 IP，.local 只作为文字备选。 想确认某台设备行不行：让它分别打开 http://电脑IP:8000/plain 与 http://名字.local:8000/plain，能出同一页就是支持。

14.3 iPhone / iPad 白屏：装一次证书就彻底解决

原因有两个，叠在一起：① 软件用的是自签名证书，苹果默认不信任；② Safari 遇到证书问题会弹 "显示详细信息 → 访问此网站"，而 iPhone 上的 Chrome / Edge / 夸克没有这个界面， 于是请求直接失败 —— 表现就是白屏、没有任何错误提示。

另外苹果有硬性规定：手动安装的证书不会自动受信任，必须在「证书信任设置」里手动打开「完全信任」。

操作（一次就好）：

  1. iPhone 用 Safari 打开 https://电脑IP:安全端口/cert （例如 https://192.168.1.19:9443/cert）
  2. 点「① 下载描述文件（iPhone / iPad 推荐）」→ 弹窗选允许
  3. 设置 → 已下载描述文件（或：通用 → VPN 与设备管理）→ 安装 → 输锁屏密码
  4. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开 「班级叫号器本机根证书」的完全信任

做完这四步，Safari、Chrome、Edge、夸克都不会再白屏，也不用每次点"继续"。 装完记得完全关掉浏览器再重开；还在白屏就是第 4 步没开。

说明：/cert、/cert.mobileconfig、 /cert.crt 是 2.0.30 新增的入口。2.0.29 及更早版本打开会是 404， 请先更新。安卓 / 鸿蒙装证书的方法在同一页里也有。

14.4 「本地网络」权限：找不到 Safari 是正常的

「设置 → 隐私与安全性 → 本地网络」管的是第三方 App 访问局域网（iOS 14 起的隐私机制）。 Safari 是系统浏览器，不走这套权限模型，永远不会出现在列表里。

列表里只会出现：① 你装过的第三方 App；② 它已经尝试过一次局域网访问 （弹过"想查找并连接本地网络上的设备"之后）。所以列表里没有 Chrome / Edge 时： 先用它打开一次 http://电脑IP:8000，弹窗选允许，再回来看。

另外三个会干扰局域网访问的手机开关，建议关掉：

开关路径建议
iCloud 私密中继设置 → 顶部 Apple ID → iCloud → 私密中继关闭
限制 IP 地址跟踪设置 → 无线局域网 → 当前 Wi-Fi 右侧 ⓘ关闭
私有无线局域网地址同上关闭（会重连一次 Wi-Fi）

还有一条硬限制：iOS 拒绝有效期超过 825 天的服务器证书。旧版本签过 10 年证书， 在 iPhone 上就是"打不开 / 服务器已停止响应"。2.0.30 起改为"根证书 10 年 + 服务器证书 365 天"， 从很旧版本升级上来的电脑第一次启动会自动重签，手机端需要重新装一次证书。

14.5 网络与路由器：多播、隔离、网段、IP 变化

情况现象处理
校园 AP 过滤多播（UDP 5353） 名字时好时坏，重启手机又好一会儿 这类网络里 .local 永远不可靠，直接用 IP
客户端隔离 / 无线隔离手机能上网，但连教室电脑也不行（IP 也不行） 换不做隔离的网络（办公室网 / 自建路由器 / 手机热点）
不同网段 / VLANIP 和名字都打不开让手机与电脑在同一网段
电脑 IP 变了（DHCP 租约）之前生成的二维码失效 见下面"固定 IP"的三种做法

固定 IP 的三种做法：

  • 路由器里做 DHCP 保留（MAC 绑定）——最推荐。电脑仍用"自动获取"，路由器每次发同一个 IP， 零冲突风险，换网络也不影响。
  • 静态 IP，且必须选在 DHCP 池外（例如池是 100–199，就用 .50 或 .240）， 掩码 / 网关 / DNS 都要填对。Windows 的静态 IP 是绑在网卡上的，不是绑 Wi-Fi 名， 白天连学校网、晚上连热点的电脑会有一边不通。
  • 什么都不改：每次用面板上显示的当前 IP，或当场重新生成二维码。

⚠️ 静态 IP 千万不要填在 DHCP 池里：路由器不知道你手动占了它，会把同一地址发给别人， 两台设备轮流掉线（Windows 会提示"IP 地址冲突"并跳到 169.254）。

另外：学校网络屏蔽 GitHub 时，软件内置的四个镜像全部不通 → 在线更新必然失败，改用安装包手动更新即可； 系统时间不准也会导致证书校验和更新校验失败，把电脑和手机都设为自动对时。

14.6 电脑端：防火墙与网卡

  • 防火墙"公用网络"拦入站。软件第一次运行会弹"是否允许访问"，必须允许（专用 + 公用都勾）。 坑在于规则是按当时的网络类型记的：之后连上一个被判为"公用"的网络（学校 Wi-Fi 常被判公用）， 规则就不生效 → 手机又连不上，重新允许一次即可。
  • 多网卡 / 虚拟网卡。电脑常有 Hyper-V 的 vEthernet、WSL、VMware、 VPN、Wi-Fi Direct（本地连接* 2），这些 IP 手机永远连不上。 2.0.30 起用系统原生 API 判断"是否有默认网关 / 是否虚拟"，默认只广播真实网卡， 设置里的「mDNS 诊断」会列出每块网卡被跳过的原因。
  • 组策略禁用 PowerShell。2.0.29 及更早版本靠 PowerShell 枚举网卡，被禁用时会退化成 "所有 IP 一起广播"；2.0.30 起不再依赖 PowerShell。
  • 没有管理员权限 / 禁止安装。用绿色版（zip 解压即用），或安装包的测试模式 （装到当前用户目录，不提权）。
  • Edge 弹「现有实例正在以提升的权限运行」。与软件无关：软件以管理员启动后拉起的 Edge 继承了管理员权限，之后普通权限再开 Edge 就会问。点是（Y），或把那个 Edge 全部关掉。
  • 摄像头 / 麦克风被占用。监控、对讲、远控需要它们；被钉钉、腾讯会议、希沃占用或被隐私设置 禁止时不可用，关掉占用程序再试。

14.7 应急四招（改程序之外）

  1. 用 IP：手机打开 http://电脑IP:8000（叫号全功能）； https://电脑IP:9443（激活 / 监控 / 远控）。
  2. 先开 /plain：不含脚本的极简页，能打开就说明网络与服务正常， 白屏是浏览器/证书的问题。
  3. 再看 /api/health：返回 JSON，能看出你连到的是哪台电脑、 走的 http 还是 https、你的 IP 和浏览器。
  4. 电脑上看 /logs：实时运行日志，可一键导出 txt （稳定版主页不显示入口，直接输网址可进）。

讲台贴纸版（可直接打印）：
手机打不开时按顺序试：① 地址换成 IP http://电脑IP:8000； ② 打开 http://电脑IP:8000/plain，能出页面说明电脑没问题； ③ iPhone 白屏：Safari 打开 https://电脑IP:9443/cert → 下载描述文件 → 安装 → 设置/通用/关于本机/证书信任设置 → 打开"完全信任"； ④ 还是不行：看电脑上的 /logs，把内容发给管理员。
