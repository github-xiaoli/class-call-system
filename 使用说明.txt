班级叫号器 使用说明
====================

【一、快速开始】
1. 将压缩包完整解压到电脑任意目录。
2. 双击 start.bat 启动（命令行窗口会自动关闭，软件在后台运行）。
   也可以双击“启动-隐藏窗口.vbs”启动，完全无窗口。
3. 本机浏览器打开：http://127.0.0.1:8000
4. 同一局域网的其他设备访问（叫号、文本消息等不受限功能）：
   - http://主机名.local:8000  （mDNS，需设备支持）
   - 或 http://本机IP:8000      （一定可用）
5. 手机端使用监控/远程控制/文件传输/设置等敏感功能时，请用安全地址：
   - https://主机名.local:安全端口  （默认 9443；若该端口被系统保留会自动改用 10443 等，以首页显示的地址为准）
   - 或 https://本机IP:安全端口
6. 退出：托盘图标右键“退出”，或在软件面板点“退出”。

【二、导入名条（CSV）】
1. 首页点“导入CSV”，选择 CSV 文件（两列：学号、姓名，带表头）。
2. 若首行不是表头，请取消“首行为表头”。
3. 选择“学号列”和“姓名列”，选“追加”或“覆盖全部”，点“确认导入”。
4. 支持 UTF-8、UTF-16、GBK/GB18030、Big5 等编码，自动适配（Excel 另存 CSV 可直接导入）。
5. 也可在“名条管理”里手动添加/删除单个名条。

【三、叫号】
1. 点击名单选择学生，或用小键盘输入学号（自动匹配姓名）。
2. 可填写备注，点“叫号”。
3. 本机自动：播放提示音 → 朗读叫号语（可重复），叫号次数自动 +1。
4. 叫号时，电脑右下角弹窗显示叫号语，学号、老师名称大字体绿色显示，可手动关闭。
5. 重复检查：同一学生在 5 分钟内被同一位老师叫过时，网页会弹窗确认是否继续。
6. 叫号记录保存在 data/calls.json 和 data/calls.log，可在网页清空。

【四、文本消息】
- 首页下方“发送文本消息”，输入文字点发送，电脑端会弹出消息并用语音读出内容。
- 该功能不受密码保护，任何能打开网页的设备都可使用。

【五、老师名称】
- 顶栏“老师”处填写并保存，保存在当前浏览器 Cookie（一年有效）。
- 老师名称不受密码保护；每个老师用自己的浏览器设置即可。

【六、叫号语 / 语音 / 提示音 / 音量】
- 叫号语模板占位符：%number% 学号、%name% 姓名、%note% 备注、%teacher% 老师名称。
- 语音合成：自动（有网自然语音/无网离线）、自然语音（edge-tts，需联网）、离线语音（comtypes SAPI）。
- 提示音：系统叮声 / 无 / 自定义 WAV，每次叫号前播放一遍。
- 叫号音量：叫号时系统音量自动切换，播完还原；取消勾选则不改变系统音量。
- 远程对讲的音量使用“叫号音量”设置。

【七、远程监控 · 对讲】
- 首页顶部“监控对讲”进入（手机请用 https 安全地址）。
- 选择摄像头和麦克风后点“开始监控”：网页实时看摄像头画面、听电脑麦克风声音。
- 只有查看时才占用摄像头/麦克风，停止或离开页面立即释放；电脑端无任何弹窗提示。
- 点“开始对讲”用手机麦克风说话，电脑端实时播放（音量同叫号设置）。

【八、远程控制】
- 首页顶部“远程控制”进入。画面上滑动即移动电脑鼠标（画面就是触控板）。
- 下方“左键单击 / 右键单击”模拟鼠标点击。
- “打开键盘输入”可弹出手机自带键盘输入文字（支持中文），也可用下方快捷键。
- 控制期间电脑右下角弹窗显示“%teacher%正在远程控制电脑”，可关闭，远程结束自动关闭。
- 控制期间电脑本机鼠标会被隐藏，结束/离开页面后自动恢复。

【九、文件传输】
- 首页顶部“文件传输”进入。可浏览电脑全部磁盘文件。
- 支持：新建文件夹、重命名、删除、下载、拖拽/选择文件上传。
- 复制/移动：点文件后的“复制/移动”，进入目标文件夹，点“粘贴到这里”。

【十、密码保护（重要）】
受保护功能：远程监控对讲、远程控制、文件传输、除“老师名称”外的所有设置、
以及名条的上传与删除（导入CSV、删除/清空名条、上传提示音）。
不受保护：叫号、文本消息、名条查看与手动添加等。
1) 本机浏览器访问首页时，右上角有“密码管理”，可创建密码：
   - 密码内容；
   - 激活时限：超过该时间未激活，密码作废；
   - 激活后有效期（天）：设备绑定从激活起持续该天数，到期后需重新激活。
2) 老师手机浏览器打开首页（https 安全地址），点右上角“激活”，输入密码：
   - 浏览器调用系统自带非对称加密（WebCrypto，ECDSA）生成公私钥；
   - 私钥不可读取、不可导出，只存在本浏览器 IndexedDB 中；
   - 公钥和密码一起发给电脑，电脑校验密码后保存公钥，密码立即失效。
3) 之后每次敏感操作：电脑下发随机挑战 → 浏览器签名 → 电脑用公钥验签 → 发 1 分钟令牌执行。
4) 密码管理页可查看每个密码的状态（未激活/已绑定/已超时/已过期），并可“撤销”：
   撤销会删除密码；若已绑定设备，会同时解除该设备绑定。
5) 手机浏览器可自行“取消激活”（右上角按钮），解除绑定。
6) 注意：激活后设备与电脑绑定；请勿清除浏览器数据、卸载浏览器，也不要对手机
   恢复出厂、刷机或重装系统，否则密钥丢失需在本机重新创建密码再激活。

【十一、HTTPS 安全端口】
- 手机端 WebCrypto 需要 HTTPS 安全上下文，软件启动时自动生成自签名证书并开启安全端口（默认 9443，被系统保留时自动换备用端口）。
- 手机首次访问 https://主机名.local:安全端口 会提示证书不受信任，点“继续访问”即可（仅局域网内自用）。
- 本机访问（127.0.0.1）不受密码保护，HTTP 即可。
- 可在设置里关闭 HTTPS 安全端口或修改端口。
- 想固定用某个端口、但它落在系统保留段时（Hyper-V / WSL 的 WinNAT 会占用动态端口段的一部分），两种办法：
  1) 在设置里勾选「占用系统保留端口时自动抢占」：启动时临时停止 WinNAT 抢到端口后再恢复（需管理员；Hyper-V/WSL 网络会中断几秒；每次启动都要抢一次）；
  2) 彻底办法（管理员执行一次并重启 Windows，把动态端口段挪到 10000 以上，9443 就不会再被占用）：
     netsh int ipv4 set dynamicport tcp start=10000 num=55535
- 查看当前被保留的端口段：netsh int ipv4 show excludedportrange protocol=tcp

【十二、托盘 / 面板 / 开机自启】
- 软件面板显示叫号记录，可隐藏到托盘。
- 托盘图标右键：显示面板 / 退出。
- 设置里可打开“开机自启”。

【十三、端口 / 主机名（mDNS）】
- 设置里可改 HTTP 端口、HTTPS 端口和主机名；端口修改后需重启生效。
- mDNS：http://主机名.local:端口 与 https://主机名.local:安全端口。
  iPhone/iPad/Mac 原生支持；部分 Windows 电脑不支持 .local，请改用 IP。

【十四、数据与配置】
- data/config.json   设置
- data/roster.json   名条
- data/state.json    叫号计数
- data/calls.json    叫号记录
- data/calls.log     叫号日志
- data/auth.json     密码/设备绑定
- data/ssl.crt/key   自签名证书
- sounds/            自定义提示音

【十五、常见问题】
1. 其他设备打不开网页？确认同一局域网；用本机 IP；检查防火墙放行。
2. 没有声音？检查电脑音量；自然语音需联网；离线语音依赖系统中文语音包。
3. 端口被占用？设置里换端口后重启。
4. 手机无法激活？确认用的是 https:// 安全地址，并已点“继续访问”通过证书提示。
5. 手机看不到摄像头？确认电脑已连接摄像头且未被其他程序占用。
